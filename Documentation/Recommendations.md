# Business Recommendations

## 1. Real-Time Monitoring

Prioritize real-time monitoring for high-risk CASH_OUT and TRANSFER transactions.

## 2. Account Investigation

Investigate origin and destination accounts that contribute disproportionately to fraud amount.

## 3. High-Value Transaction Controls

Introduce additional verification for transactions within the highest transaction-value percentile.

## 4. Balance Validation

Strengthen transaction validation using origin and destination balance consistency checks.

## 5. Risk Model Improvement

Review the rule-based risk scoring framework periodically and incorporate additional behavioral, historical, and account-level features.

## 6. Continuous Monitoring

Use Power BI reporting to monitor fraud indicators, transaction trends, and risk categories over time.
