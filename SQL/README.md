# PostgreSQL Analysis

This folder contains SQL scripts used for financial transaction, fraud, and risk analysis.

## SQL Files

### 01_schema_and_data_quality.sql

Contains:

- Table creation
- Data quality checks
- Null checks
- Duplicate checks
- Basic dataset validation

### 02_transaction_analysis.sql

Contains:

- Transaction volume analysis
- Transaction type analysis
- Transaction amount analysis
- Aggregation and filtering

### 03_fraud_investigation.sql

Contains:

- Fraud transaction analysis
- Fraud rate analysis
- Fraud amount analysis
- High-value fraud analysis
- Fraudulent account analysis

### 04_risk_analysis.sql

Contains:

- Risk category analysis
- Risk score analysis
- Balance anomaly analysis
- Ranking analysis
- Window functions
- CTEs
- Subqueries

## Database

PostgreSQL
