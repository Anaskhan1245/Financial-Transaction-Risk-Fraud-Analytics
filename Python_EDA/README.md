# Python EDA

This folder contains the Python-based exploratory data analysis and feature engineering performed for the Financial Transaction Risk & Fraud Analytics project.

## Analysis Covered

- Data loading and inspection
- Data quality checks
- Fraud distribution
- Transaction type analysis
- Fraud amount analysis
- High-value transaction analysis
- Balance anomaly analysis
- Feature engineering
- Risk score calculation
- Risk categorization
- Business-focused exploratory analysis

## Main Notebook

`Financial_Transaction_Risk_Fraud_Analytics_EDA.ipynb`

- Pandas
- NumPy
- Matplotlib
- Seaborn
