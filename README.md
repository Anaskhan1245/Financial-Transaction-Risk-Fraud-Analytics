# Financial Transaction Risk & Fraud Analytics

An end-to-end data analytics project focused on analyzing financial transactions, identifying potential fraud patterns, detecting balance anomalies, evaluating transaction risk, and generating actionable business insights using Python, PostgreSQL, SQL, Power BI, DAX, and Power Query.

---

## 📌 Project Overview

Financial transactions generate large volumes of data that can contain unusual transaction behavior, high-value transfers, account-level concentration, balance inconsistencies, and other potential fraud indicators.

This project analyzes transaction-level financial data to understand:

- Transaction behavior and volume
- Transaction amount distribution
- Fraud transaction patterns
- Fraud amount concentration
- High-value transaction risk
- Transaction-type risk
- Balance anomalies
- Account-level fraud concentration
- Risk categories
- Potentially suspicious transaction patterns

The project follows an end-to-end analytics workflow from data exploration and feature engineering to SQL analysis and interactive Power BI reporting.

---

## 🎯 Business Objectives

The main objectives of this project are:

- Analyze overall financial transaction activity.
- Identify transaction types associated with higher fraud risk.
- Measure fraud transaction rate and fraud amount.
- Identify high-value transactions with elevated fraud risk.
- Detect inconsistencies between transaction amounts and account balances.
- Analyze fraud concentration across origin and destination accounts.
- Develop a rule-based transaction risk scoring framework.
- Build an interactive Power BI dashboard for fraud-risk monitoring.
- Convert analytical findings into actionable business recommendations.
